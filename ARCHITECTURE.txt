┌──────────────────────────────────────────────────────────────────────────┐
│                          CHEF SERVICE                                    │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  GET    /api/chef/pendentes          → Lista pedidos pendentes          │
│  GET    /api/chef/em-preparo         → Lista pedidos em preparação      │
│  GET    /api/chef/prontos            → Lista pedidos prontos            │
│  PATCH  /api/chef/preparar/{id}      → Marcar como em preparação        │
│  PATCH  /api/chef/pronto/{id}        → Marcar como pronto               │
│                                                                          │
│  Responsabilidades:                                                      │
│  ✓ Gerenciar status dos pedidos na cozinha                             │
│  ✓ Visualizar pedidos para preparação                                  │
│  ✓ Marcar quando está pronto                                           │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│                       GARCOM SERVICE                                     │
├──────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  POST   /api/garcom/criar-pedido          → Criar novo pedido           │
│  GET    /api/garcom/listar-pedidos        → Listar todos os pedidos     │
│  GET    /api/garcom/{id}                  → Obter detalhes do pedido     │
│  PUT    /api/garcom/editar-pedido/{id}    → Editar pedido existente     │
│  DELETE /api/garcom/remover-pedido/{id}   → Remover pedido              │
│  DELETE /api/garcom/remover-prato/{id}/{id} → Remover prato do pedido  │
│                                                                          │
│  Responsabilidades:                                                      │
│  ✓ Criar novos pedidos                                                 │
│  ✓ Editar/modificar pedidos                                            │
│  ✓ Remover pedidos ou pratos                                           │
│  ✓ Listar todos os pedidos                                             │
│                                                                          │

╔═══════════════════════════════════════════════════════════════════════╗
║ OPÇÃO 2: Localmente (3 Terminais)                                    ║
╚═══════════════════════════════════════════════════════════════════════╝

Terminal 1:
$ cd MicroServices/ApiGateway
$ dotnet run

Terminal 2:
$ cd MicroServices/ChefService
$ dotnet run

Terminal 3:
$ cd MicroServices/GarcomService
$ dotnet run


╔═══════════════════════════════════════════════════════════════════════╗
║ OPÇÃO 3: Visual Studio                                               ║
╚═══════════════════════════════════════════════════════════════════════╝

1. Abra Solutionkitchen.sln
2. Clique direito na solução > Propriedades
3. Configure múltiplos projetos de inicialização:
   - ApiGateway → Start
   - ChefService → Start
   - GarcomService → Start
4. Pressione F5
